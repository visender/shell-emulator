# Эмулятор командной оболочки UNIX

Консольный эмулятор командной строки UNIX-подобной ОС
(практическая работа №1, вариант 5, дисциплина «Конфигурационное управление»).

Эмулятор имитирует работу в терминале: выводит приглашение, читает команды
пользователя, разбирает их с учётом кавычек и выполняет встроенные команды.

## Требования

- Python 3.10 или новее (зависимостей нет, только стандартная библиотека).

## Структура проекта

```
src/shell_emulator/
    __main__.py   точка входа (python -m shell_emulator)
    shell.py      цикл REPL, приглашение, обработка ошибок
    parser.py     разбор строки на команду и аргументы
    commands.py   встроенные команды
tests/            модульные тесты (unittest)
run.bat, run.sh   запуск эмулятора
test.bat, test.sh запуск тестов
```

## Функции

### Приглашение к вводу

Формируется из реальных данных ОС: имени пользователя и имени компьютера.

```
username@hostname:~$
```

### Разбор командной строки

- аргументы разделяются пробелами и табуляциями;
- `"..."` и `'...'` объединяют несколько слов в один аргумент;
- внутри `"..."` можно экранировать `\"` и `\\`;
- вне кавычек `\` экранирует следующий символ (`My\ Documents`);
- незакрытая кавычка — синтаксическая ошибка.

### Команды

| Команда       | Описание                                                   |
|---------------|------------------------------------------------------------|
| `ls [арг...]` | заглушка: выводит своё имя и аргументы                      |
| `cd [каталог]`| заглушка: выводит своё имя и аргументы, не более 1 аргумента |
| `exit [код]`  | завершает работу с указанным кодом (по умолчанию 0)          |

### Обработка ошибок

| Ситуация                   | Сообщение                                          | Код |
|----------------------------|----------------------------------------------------|-----|
| неизвестная команда        | `foo: command not found`                           | 127 |
| незакрытая кавычка         | `syntax error: unexpected EOF while looking for ...` | 2 |
| лишние аргументы `cd`      | `cd: too many arguments`                           | 1   |
| нечисловой код `exit`      | `exit: abc: numeric argument required`             | 1   |

Конец ввода (Ctrl+D в Linux, Ctrl+Z и Enter в Windows) завершает эмулятор.

## Сборка и запуск

Сборка не требуется. Запуск эмулятора:

```bat
run.bat
```

```sh
./run.sh
```

Запуск тестов:

```bat
test.bat
```

```sh
./test.sh
```

## Пример использования

```
bozhi@Visender:~$ ls
ls: args=[]
bozhi@Visender:~$ ls -l "My Documents" 'single quoted' plain\ escaped
ls: args=['-l', 'My Documents', 'single quoted', 'plain escaped']
bozhi@Visender:~$ cd /home/user
cd: args=['/home/user']
bozhi@Visender:~$ cd a b
cd: too many arguments
bozhi@Visender:~$ cd "unclosed
syntax error: unexpected EOF while looking for matching `"'
bozhi@Visender:~$ foo --bar
foo: command not found
bozhi@Visender:~$ exit abc
exit: abc: numeric argument required
bozhi@Visender:~$ exit 7
```
